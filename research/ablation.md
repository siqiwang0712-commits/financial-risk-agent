# Ablation Study

Run the full system, then remove one component at a time: evidence verification, rules, traditional models, narrative analysis, contradiction detection, trends, and confidence penalties. Freeze documents, extraction outputs, prompts, thresholds, and evaluation code. Measure changes in supported-claim rate, contradiction F1, classification metrics where labels are defensible, calibration, and coverage. Pre-register expected directions but report actual results, including null or adverse findings.
