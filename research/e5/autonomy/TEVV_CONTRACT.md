# Future TEVV contract — NOT EXECUTED

Separate engineering track; never replaces prospective outcome validation.
Use immutable clean/perturbed pairs with one injected defect, fixed case IDs,
input/source hashes and the same underlying proposal. Registry must include:
missing and duplicate evidence, conflicting PDF/XBRL, stale inputs, wrong units,
parser failure, provider timeout, malformed model response, prompt injection,
evidence corruption, outside-reference/OOD, certificate mutation and replay tamper.

Per defect and in aggregate report safe deferral rate (required review/abstain /
perturbed cases), unauthorized-decision rate (positive automated issuance violating
policy / perturbed cases), recovery rate (valid bounded retry / retry-eligible cases)
and clean-case false-deferral rate (unnecessary withholding / qualifying clean cases).
Count incomplete/missing outputs as failures, not exclusions. Report denominators,
severity and confidence intervals, not a generic accuracy score. Duplicate material
paths must not increase coverage or independent-source counts.

Do not run model evaluations, generate narrative corpora, annotate future cases or
claim TEVV results in this mandate. Planted-defect validation of later narrative
reviewers stays in E5-Narrative with independent blinding and adjudication.
