# Dataset Card

## Released evaluated set

`finrisk-sec-mini-v1` contains three FY2024 US public-company observations: Apple, Microsoft and Intel. Sources are official SEC 10-K filings. Values are manually reviewed statement observations in USD millions; claim spans are exact filing excerpts. `annotations.csv` separates labels and review state from system predictions.

The split is company-disjoint: Apple train, Microsoft validation, Intel test. The set has two normal and one risk label and is single-reviewed. It is a pilot for mechanics and error discovery, not a statistically useful benchmark.

## Gold-label definition

The v1 risk label is a single-reviewer holistic financial-distress judgement based on filed statements and disclosures. This definition is too subjective for confirmatory research and is retained only for continuity. Contradiction labels ask whether the quoted optimistic statement materially conflicts with at least two relevant numeric indicators after considering disclosed context.

No gold label is generated by FinRisk-Agent, its rules, ratios, model outputs or aggregate score. System outputs live only under `research/results`.

## Planned 30-company protocol

`candidate_registry_30.csv` pre-registers 30 cross-sector candidates before acquisition. It aims for approximately balanced distress/non-distress strata and uses 2023 features with a 2024 forward outcome. Proposed gold distress is an independently computed future outcome: bankruptcy/restructuring/going-concern disclosure, or at least two of negative net income, negative operating cash flow, and negative free cash flow in the following annual filing. Feature-year values only are visible to models; outcome-year values are label-only.

Candidates marked `pending_sec_download` are **not benchmark examples and are not included in results**. The SEC blocked both Company Facts and bulk ZIP requests from the current network. Promoting a candidate requires source hash, accession, fiscal period, unit/concept provenance, independent dual review and adjudication.

## Leakage controls

- Split by company, never by report page or year row.
- Outcome-year label fields are inaccessible to prediction code.
- Freeze mappings, prompts and thresholds before test execution.
- Never balance by using system predictions.
- Do not derive gold extraction values from the parser being evaluated.

## License and privacy

Only public SEC filings and compact derived annotations are intended for release. Large raw SEC caches, private reports, API keys and LLM logs are excluded from Git.
