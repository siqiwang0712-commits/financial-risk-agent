# v0.3.2 — Reproducibility & Runtime Integrity

Draft release notes. No v0.3.2 tag or GitHub Release has been created.

This release hardens replay semantics, PostgreSQL runtime selection, durable credentials,
tenant/API trust boundaries, provenance completeness, benchmark abstention semantics,
fusion reason codes, versioned narrative-consistency policy, frontend deployability and
container defaults. It adds prospective schema and standalone-period FCF methodology
versions without changing historical v0.3.1 experiments.

E1/E2/E3 and `research/results/public_v1` remain byte-for-byte unchanged. Their results
are historical frozen evidence and are not regenerated by current code. Predictive
superiority and probability calibration remain not established.

Local validation: 134 Python tests passed with 90.49% coverage; one PostgreSQL service
test was skipped because this machine has no PostgreSQL/Docker runtime. Four frontend
semantic tests, TypeScript, Next.js production build, Ruff, frozen replay and whitespace
checks passed. PostgreSQL migration/restart validation remains delegated to the configured
CI service until run in an environment with PostgreSQL.
